# CurCrossbreed

CurCrossbreed is a Rubblesonic modular effects plugin containing seven selectable
processing modules, including the TapeBox-lite tape saturation and transport
stage.

## Build and install

The checked-in Xcode project builds AU, VST3, and Standalone targets. A Release
build installs the AU and VST3 bundles into the current user's macOS Audio Plug-Ins
folders through the project build phases.

See [docs/JUCE_PLUGIN_BUILDING_MEMORY.md](docs/JUCE_PLUGIN_BUILDING_MEMORY.md)
for host and PatchWork testing notes.
